# Project Zomboid Mods & Tools Catalog Guide

- This repository is the public catalog for independently versioned Project Zomboid projects.
- Do not copy runtime source from child repositories into this catalog.
- Keep repository, Workshop, support status, and verification claims accurate.
- Preserve independent histories and release cycles; do not add Git submodules unless explicitly requested.
- Keep temporary compatibility fixes clearly labeled and remove or archive their catalog entries when upstream fixes make them obsolete.
- Before claiming completion, run `node tests/catalog-links.test.cjs` and `git diff --check`.
